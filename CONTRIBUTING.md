# Contributing to SortSmith

Thank you for helping improve SortSmith.

1. Open or reference an issue for user-visible changes when practical.
2. Create a focused branch from `main`.
3. Keep filesystem behavior reversible and previewable.
4. Add or update tests for behavior changes and bug fixes.
5. Run formatting, Clippy, Rust tests, frontend type checks, frontend tests, and builds.
6. Never commit personal files, real credentials, or private paths in fixtures.
7. Use Conventional Commits such as `feat:`, `fix:`, `test:`, and `docs:`.

For security reports, do not open a public issue; use the process in `SECURITY.md`.
